Le clavier traducteur pour discuter dans toutes les langues

Lisez ce qu’on vous écrit dans votre langue et répondez dans la sienne, directement dans WhatsApp, Telegram, Instagram ou n’importe quelle app. La traduction se fait sur votre iPhone.

Essai gratuit de 7 jours · iPhone avec iOS 26 ou ultérieur

Comment ça marche

1Copiez le message

Maintenez le doigt sur le message reçu et touchez « Copier ». Le clavier le traduit aussitôt dans votre langue.

2Écrivez dans votre langue

Rédigez votre réponse comme d’habitude et touchez « Traduire » : elle est remplacée par la traduction, prête à envoyer.

3Vérifiez et envoyez

En dessous, vous voyez ce que dit votre message dans votre langue, pour l’envoyer en toute confiance.

Questions fréquentes

Fonctionne-t-il avec WhatsApp ?

Oui. Il fonctionne dans toutes les apps où vous écrivez : WhatsApp, Telegram, Instagram, Messenger, Gmail, LinkedIn et d’autres.

Est-ce gratuit ?

Vous avez 7 jours gratuits. Ensuite 2,99 € par mois ou 19,99 € par an, ou 39,99 € une seule fois. Écrire avec le clavier est toujours gratuit.

Pourquoi demande-t-il « Autoriser l’accès complet » ?

iOS l’exige pour que le clavier puisse lire le message copié, utiliser l’IA si vous l’activez et partager les réglages avec l’app. Il n’enregistre ni n’envoie ce que vous tapez.

Fonctionne-t-il hors ligne ?

Oui. Avec la traduction d’Apple, une fois les langues téléchargées, la traduction se fait sur l’iPhone sans connexion.

Quelles langues traduit-il ?

Plus de 20, dont l’anglais, l’espagnol, l’allemand, l’italien, le portugais, le néerlandais, le chinois et le japonais.

Existe-t-il une version Android ?

Pour l’instant, il est disponible sur iPhone avec iOS 26 ou ultérieur.

Commencez en une minute

  1. Installez l’app et ouvrez le guide de démarrage.
  2. Dans Réglages iOS → Claviers, activez le clavier et « Autoriser l’accès complet ».
  3. Dans n’importe quelle conversation, maintenez 🌐 et choisissez le clavier.
  4. Copiez le message reçu pour le lire traduit ; écrivez dans votre langue et touchez Traduire.
